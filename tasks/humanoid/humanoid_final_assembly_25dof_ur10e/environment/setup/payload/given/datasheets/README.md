# Actuator data pages

Five pages, a page per actuator type of the robot, types A to E. `module.json` names the type of
every joint.

Each page gives the actuator's outline and mass, the hole pattern of its output flange where the model has one, and
the values of the unpowered actuator that the cell simulates at the joint: its holding friction, its damping and its
reflected inertia. For every actuator type these are the values of the cell manual, section 6; the
values at the ankle joints, which a linkage drives, are given only in the cell manual. The holding friction is a
holding value read conservatively from the maker's test data, not a measured back-driving torque.
No joint of this robot is powered in this station.

Each page is an image of 4200 by 2970 pixels with lettering about 16
pixels high: read a page from crops at full size. A whole page shown reduced does not show its smallest text.
