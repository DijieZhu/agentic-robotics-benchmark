# The author's image-only pilot and its checks

`oracle_run.py` and `architecture.py` are the task author's pilot that flies the rescue from the two onboard images
alone, and the `check_*.py` / `test_*.py` files are the author's own studies made with it. They are kept as the
author's design record.

They are not the task's reference: `solution/` flies the token-gated privileged pilot (`solution/oracle/pilot.py`),
the hidden set was chosen with that pilot (`../selection.md`), and nothing here is run by setup, by grading or by
validation. No score band or threshold of the task was derived from this pilot.
