# cells/

The desktop cells of the DA-6: start with `cell_manual.md`. The example scenes are scene descriptions as the controller receives them at `setup` (argument `cell`).

- `README.md`: this index
- `cell_manual.md`: integration manual of the three desktop cells: objects, frames, scene description, survey tolerance, setup arguments, clamped tools (part, needle and holder, the jaw's pad gap), reach
- `example_scene_bins.json`: scene description of an example bin placement installation
- `example_scene_dispense.json`: scene description of an example adhesive dispensing installation
- `example_scene_shelf.json`: scene description of an example shelf picking installation
