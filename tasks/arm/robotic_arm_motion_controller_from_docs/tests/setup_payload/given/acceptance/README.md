# acceptance/

The site acceptance test of the DA-6 motion controller: start with `acceptance_spec.md`. The example job lists belong to the example scenes of `../cells/`.

- `README.md`: this index
- `acceptance_spec.md`: site acceptance test: the three runs, one on each unit (home pose, calls, failures, a contact ending the cell), the jobs, the measurements, the scoring, the gates
- `example_jobs_bins.json`: job list of the example bin placement installation, with the cell's `tool`
- `example_jobs_dispense.json`: job list of the example adhesive dispensing installation, with the cell's `tool`
- `example_jobs_shelf.json`: job list of the example shelf picking installation, with the cell's `tool`
