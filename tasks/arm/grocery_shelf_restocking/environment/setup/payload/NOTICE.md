# NOTICE - sources

- **The robot** is the Franka Panda model of robosuite 1.5.2 (MIT), installed unmodified in the task image;
  `shelf_sim.py` loads its files.
- **What the simulation touches** (the gondola bay and its neighbours, the cart and tote, the products) is built
  from MuJoCo primitives in `shelf_sim.py` and `shelf_world.py`.
- **What the cameras draw** is generated by this task's own code (`shelf_scene.py`, `shelf_parts.py`,
  `shelf_geom.py`, `shelf_tex.py`, `shelf_looks.py`: the gondola, the products' print and date-code labels, the
  aisle's stocked bays, floor, ceiling and walls) and drawn by MuJoCo 3.16's Filament renderer on the CPU
  (`shelf_render.py`). The pictures and the few props it reads (a hand truck, cartons, crates, a pallet, a stock
  cart: licensed store-room models, for display only) are in `/opt/task-assets/payload/render`.
