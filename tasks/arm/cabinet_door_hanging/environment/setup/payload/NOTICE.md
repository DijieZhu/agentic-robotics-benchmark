# NOTICE - sources

- **The robots** are the Franka Panda model of robosuite 1.5.2 (MIT), installed unmodified in the task image;
  `door_sim.py` loads its model files (robosuite itself is not imported). The right arm's vacuum cup tool is built
  from MuJoCo primitives in `door_sim.py`.
- **Everything else the simulation touches** (the table, the wall cabinet and its hinges, the doors, the racks, the
  pins and their stands, the contact shapes of the fitter's things) is built from MuJoCo primitives in `door_sim.py`.
- **What the cameras draw** is generated by this task's own code (`door_scene.py`, `door_parts.py`, `door_geom.py`,
  `door_looks.py`) and drawn by MuJoCo 3.16's Filament renderer on the CPU (`door_render.py`). The room round the
  bench (a living room and kitchen of a licensed interior model pack, decimated, for display only), four oak colour
  maps (composed from Poly Haven's `oak_veneer_05`, CC0) and the image light (a path-traced probe of that room; sky:
  Poly Haven's `kloofendal_48d_partly_cloudy_puresky`, CC0) are in `/opt/task-assets/payload/render`.
