# The public-observation reference (review material)

The author's reference of v8: it surveys with the UAV, measures the passages and the two covers' heights from
the nadir frames, registers the Go1's launch pose on the bollard caps seen by the mast camera, and walks with a
gait that has two fixed postures (`walk.py`). It assumes the nominal load and the nominal fittings, so on the
per-site properties of version 5 it is a control, not a solution: `tests/review/controls.py public`.
It is never installed in a participant's sandbox.
